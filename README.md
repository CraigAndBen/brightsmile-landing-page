# 🦷 BrightSmile Dental Clinic – Landing Page

A modern, responsive dental clinic landing page built using React and Tailwind CSS. This project is designed as a portfolio demo to showcase front-end development skills and clean UI/UX design for healthcare websites.

---

## 🌐 Live Demo

🔗 https://brightsmile-dental.craigben.com

---

## 🚀 Features

* ✅ Fully responsive design (mobile, tablet, desktop)
* ✅ Clean and modern UI
* ✅ Smooth scrolling navigation
* ✅ Reusable React components
* ✅ Simple appointment form UI
* ✅ Optimized layout for user experience

---

## 🛠️ Built With

* React (Functional Components)
* Tailwind CSS
* Vite (for fast development)

## ⚙️ Installation & Setup

Clone the repository:

```
git clone https://github.com/your-username/brightsmile-dental.git
```

Navigate into the project:

```
cd brightsmile-dental
```

Install dependencies:

```
npm install
```

Run the development server:

```
npm run dev
```
